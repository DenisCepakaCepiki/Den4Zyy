# 💖 Happy Girlfriend Day Website

Website hadiah spesial untuk pasangan dengan animasi modern, efek romantis, dan desain premium berbasis **HTML, CSS, dan JavaScript**.

Website ini dibuat untuk memberikan pengalaman seperti membuka hadiah digital:

✨ Loading Animation  
💖 Floating Hearts  
🌌 Aurora Background  
⭐ Stars Effect  
🌸 Sakura Petals  
💌 Love Letter dengan Typing Effect  
📸 Gallery Foto  
💞 Relationship Timeline  
⏳ Love Counter  
🎵 Background Music  
🎉 Confetti Ending  
📱 Responsive Mobile & Desktop

# ⚙️ Custom Website

## 💑 Mengubah Nama Pasangan

Buka:

```
index.html
```

Cari:

```html
Zyy
```

Ganti dengan nama pasangan kamu.

Contoh:

```html
Untuk
<br>
Nama Pasangan ❤️
```

---

# 💌 Mengubah Isi Surat

Buka:

```
script.js
```

Cari:

```javascript
const stories = [
```

Contoh:

```javascript
{
title:"Happy Girlfriend Day ❤️",

image:"assets/images/1.jpg",

text:`
Isi pesan romantis kamu di sini...
`
}
```

---

# 📸 Mengganti Foto

Masukkan foto ke:

```
assets/images/
```

Gunakan nama:

```
1.jpg
2.jpg
3.jpg
4.jpg
5.jpg
6.jpg
```

Atau ubah path di:

```
index.html
```

---

# 🎵 Mengganti Musik

Masukkan lagu ke:

```
assets/music/
```

Nama default:

```
love.mp3
```

Jika nama berbeda, ubah:

```html
<audio id="bgMusic">

<source src="assets/music/love.mp3">

</audio>
```

---

# ⏳ Mengatur Countdown Hubungan

Buka:

```
script.js
```

Cari:

```javascript
const relationshipDate =
new Date("2025-01-01");
```

Ubah tanggal sesuai tanggal mulai hubungan.

Format:

```
YYYY-MM-DD
```

Contoh:

```javascript
const relationshipDate =
new Date("2024-08-15");
```

# 🌐 Deploy ke GitHub Pages

## 1. Upload Repository

Upload semua file:

```
index.html
style.css
script.js
assets/
```

---

## 2. Aktifkan GitHub Pages

Masuk:

```
Repository
↓
Settings
↓
Pages
```

Pilih:

```
Deploy from a branch
```

Branch:

```
main
```

Folder:

```
/root
```

Klik:

```
Save
```

---

Website akan tersedia di:

```
https://username.github.io/nama-repository/
```
